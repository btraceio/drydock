Window-centric

A worktree window is the session. The agent console opens as a pinned editor tab, first in the tab row, so it can split beside the code it is editing. There's no Drydock tool window. The catalog lives where the IDE already lists projects: the title-bar Project widget, a status-bar widget and Recent Projects. Review is a tab in the Commit tool window.

Who owns what Durable sessionProject widget / Recent Projects entry Live processProcessHandler in the worktree Project Presentationeditor tab (restorable virtual file) Windowone Project per worktree, titled by session
Fits — Project = folder = window is the IDE's own fact model; editor tabs already persist and restore, and closing one hides it rather than deleting it; the agent stays centre stage.
Strains — a terminal hosted in an editor tab is less proven than Run; the catalog sits in popups, so it's harder to see at a glance; lots of windows on a laptop screen.
