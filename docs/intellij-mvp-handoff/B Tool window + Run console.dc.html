Drydock tool window + Run console

The v3 direction, refined. A dedicated Drydock tool window (right) lists the app-wide catalog, with This window pinned on top. The agent runs as Run-tool-window content in its worktree's window, owned by Drydock's execution service, so there's no native Rerun and no persisted run configuration. Review is the tool window's second tab.
