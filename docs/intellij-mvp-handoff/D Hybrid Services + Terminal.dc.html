D

Hybrid: Services + Terminal + Commit view

The catalog lives in Services, as in A, but the detail pane is a summary card, not a console. The agent shows up where CLI users expect it, a Terminal tab. The tab is only a view: the process runs in a detached host (the existing tmux persistence), so closing the tab detaches it. Review decorates the Commit tool window's own Changes tree.

Fits — Terminal is where people already run claude/codex; agents keep working through IDE restarts; review happens in the view people already commit from.
Strains — Terminal-tab lifecycle is where v2 broke, so this only works if the tab owns nothing; tmux means no Windows; it reverses v3's "project close stops execution", which needs a decision.
